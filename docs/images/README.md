Images folder for project README assets

Place your visual assets here to display on GitHub:
- logo.png        # project logo (recommended ~512x512)
- screenshot.png  # app screenshot (recommended 1280x720)

Once added, reference them from `README.md` or `README.tr.md` like:
```
![Logo](docs/images/logo.png)
![Screenshot](docs/images/screenshot.png)
```
